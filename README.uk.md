# voice-mod — голосові команди для Claude Code

[English](README.md)

Керування Claude Code голосом без кнопки (для режиму коду: у звичайному чаті
голосовий режим уже є). Кажете «Клоде, …», локальний Whisper розпізнає
українську, команда йде в чат як промпт із позначкою 🎙.

- **Слово-активатор** «Клоде» (змінюється в ⚙), ловиться вже під час фрази.
- **Живий текст** команди в рядку над полем вводу, поки ви говорите.
- **Два режими кінця команди**: пауза в мові або стоп-слово («Роби») — тоді
  можна диктувати з паузами, до 5 хв.
- **Слово скасування** («Відміна», змінюється в ⚙): скажіть його в кінці — команду відкинуто,
  у чат нічого не йде. Діє в обох режимах, а після диктовки — і окремою фразою
  («… Роби» відправляє, «Відміна» відкидає все зібране). «Клоде, відміна» ще й відповідає
  «ні» на висячу картку підтвердження.
- **Поки агент працює**: команда, сказана посеред його ходу, доходить до агента на наступному
  кроці — як повідомлення, набране в чаті під час роботи; якщо кроків уже нема — одразу після
  ходу. Захист руйнівних дій вмикається, як для ходу, запущеного голосом.
- **Озвучення відповідей** (опційно, типово вимкнено): агент закінчує останню відповідь ходу
  коротким блоком «🔊 Озвучити:», а локальний голос (Piper) читає вголос лише його.
  Ставиться однією кнопкою, видаляється однією. Див. [Озвучення відповідей](#озвучення-відповідей-опційно).
- **Звуковий сигнал**: після активатора, після команди, обидва або вимкнено.
- **Безпека**: модель чистить текст і позначає ризикові команди; руйнівні дії в
  ході, запущеному голосом, зупиняються до підтвердження кнопкою чи текстом.
- **Розпізнавання локально**: GPU NVIDIA (large-v3, ~0.5–1.5 с на фразу) або
  CPU (повільніше). Звук нікуди не відправляється.

Лише Windows.

## Встановлення

Потрібні Windows, Python 3.10+ з лаунчером `py` і ~6 ГБ на диску.

1. Слухач (Python-бібліотеки й моделі whisper, ~5 ГБ) — з копії репозиторію:

   ```powershell
   git clone https://github.com/Parsec1498/claude-code-voice-mod
   cd claude-code-voice-mod
   powershell -ExecutionPolicy Bypass -File install.ps1        # з GPU NVIDIA
   powershell -ExecutionPolicy Bypass -File install.ps1 -Cpu   # без GPU
   ```

   Усе лягає в `%USERPROFILE%\.claude\voice-mod` (venv, моделі); саму копію потім можна видалити.

2. Сам мод — у терміналі Claude Code:

   ```
   /plugin install voice-mod --marketplace Parsec1498/claude-code-voice-mod
   ```

   На запит `Add marketplace?` — `y`, далі Enter (область user). Із звичайної оболонки:
   `claude plugin install voice-mod --marketplace Parsec1498/claude-code-voice-mod`. У застосунку на ПК:
   «+» біля поля вводу → Plugins → Add marketplace (`Parsec1498/claude-code-voice-mod`) → Add plugin.

## Як користуватись

| Елемент | Що робить |
| --- | --- |
| ✖ | скасувати команду: видно лише коли слухач у режимі команди (почув активатор, диктуєте чи розпізнається); у чат нічого не йде — кнопкова версія слова скасування; поки звучить відповідь, обриває озвучку |
| 🎤 / 🔇 | мікрофон; вимкнений — слухач не працює і не тримає пам'ять |
| ⚙ | налаштування (див. нижче) |
| 🕘 | історія: що чув розпізнавач і що пішло командою |
| 🎧 Сюди | перевести голос у цей чат (видно в чатах, що не слухають) |
| 🔓 Авто / 🔒 Закріплено | режим у чаті, що слухає: Авто — голос іде за чатом, де ви пишете; Закріплено — лишається тут до 🎧 чи голосової команди |

**Куди йде голос — видно завжди.** У рядку мода: «Голос тут» або «Голос → «Запуск бота»»
(🔒 — закріплено там); під час диктування живий текст теж із ціллю:
«🎙 → «Запуск бота»: перезапусти…». Кожне перемикання — сповіщення з причиною («ви написали
там», «кнопкою», «голосова команда») і запис в історії 🕘.

Команди: `/voice-panel` (історія), `/voice-here`, `/voice-lock`, `/voice-mute`,
`/voice-confirm`, `/voice-cancel`, `/voice-safe`.

**Зміна чату голосом (експериментально).** «Клоде, зміна чату Запуск бота, перезапусти
сервер» — команда йде в чат «Запуск бота» (назва як у бічній панелі; довгу можна почати
першими словами), голос лишається там. Без команди — голос просто переходить у той чат.
Фраза діє лише одразу після слова-активатора; змінюється в ⚙. Не знайшовся чат чи
схожих кілька — команда нікуди не йде. Потрібно, щоб інструмент ListAgents був
дозволений без питання; на екран застосунок той чат сам не виводить.

## Налаштування ⚙

Зміни діють одразу — без перезапуску сесій. Біля кожного поля
кнопка ⓘ: натисніть (чи наведіть курсор) — з'явиться підказка, через 10 с зникне.

**Базові** (видно одразу):

- **Мова** — українська чи англійська. Міняє інтерфейс мода, мову розпізнавання і типові
  слова (англійською: «Claude» / «Done»). Свої слова лишаються як є.
- **Слово-активатор** — кілька варіантів через кому; порожньо — типові для мови.
- **Автозавершення** — команда закінчується паузою; вимкнено — до стоп-слова.
- **Стоп-слово** — видно лише з вимкненим автозавершенням (інакше слухач його не слухає).
  Старіший ⚙ записував «Роби» в поле навіть порожнім — таке значення лишається «своїм» і
  після перемикання на англійську; щоб діяло типове для мови, очистіть поле.
- **Слово скасування** — кілька варіантів через кому; порожньо — типове для мови. Діє в обох
  режимах (на відміну від стоп-слова), тож поле видно завжди.
- **Звуковий сигнал** — після активатора, після команди, обидва або вимкнено.
- **Озвучувати відповіді** — поки модуль не встановлено, тут кнопка «⬇ Встановити озвучення»,
  потім перемикач (див. [нижче](#озвучення-відповідей-опційно)).
- **Перезапустити слухача.**

**▸ Розширені** (згорнуто), трьома групами:

- *Розпізнавання.* **Моделі** — мала (шукає слово-активатор) і велика (розпізнає команду).
  Списки від найлегшої до найважчої: якість ★ (орієнтовна, окремо для мови), пам'ять GPU/RAM
  (виміряна), ⬇ — моделі нема на диску. Вибір такої моделі і є згода на завантаження;
  поки вона качається, слухач працює зі старими. Підміна — між фразами, 10–30 с без голосу.
  Порожній вибір — типові (GPU: small + large-v3, CPU: base + large-v3-turbo).
  Далі — підказка розпізнавачу, слова-підказки, словник виправлень і самодоповнення (нижче).
- *Обробка команди.* Що йде в чат: «Сирий текст» (без моделі), «Очищене + сире» (типово)
  або «Лише очищене». Модель обробки (haiku чи sonnet), тайм-аут, **інструкція моделі** —
  її повний текст можна правити («Типова» повертає вбудовану) — і короткі доповнення до неї
  («MyApp пиши латиницею»). Модель обробки отримує лише інструкцію, слова-підказки (щоб
  писати терміни проєкту правильно й там, де словник не встиг), доповнення і текст команди
  (вже виправлений словником) — більше нічого. Перевірка руйнівних дій не
  вимикається в жодному режимі; сире завжди видно в 🕘.
- *Безпека й чати.* Безпечний режим і фраза **зміни чату (експериментально)**.
- *Озвучення* (з'являється, коли озвучення встановлено). Голос для української, голос для
  англійської і «Видалити озвучення».

**Під свій проєкт** — у ⚙ поля «Підказка розпізнавачу» (зразок фрази з вашими
словами), «Слова-підказки» (назви через кому) і «Словник виправлень» — типові помилки
розпізнавання, `що чує | варіант => як писати`. Словник правиться прямо в ⚙ (Enter —
зберегти, Shift+Enter — новий рядок; під полем видно, скільки правил діє і які рядки
биті) або кнопкою «Відкрити» — у вашому редакторі. Файл —
`%USERPROFILE%\.claude\voice-mod\glossary.txt`, слухач перечитує його сам.

- **«Згенерувати»** — агент Opus (лише читає) досліджує проєкт, бачить почуте розпізнавачем,
  ваші повідомлення в цьому чаті й назви інших чатів і пропонує правила словника та
  слова-підказки. Пропозиція лягає **чернеткою** в поля — збережіть Enter або «Відкиньте».
  Кілька хвилин; ⚙ можна закрити.
- **Агенти доповнюють словник** (вимикач у ⚙, типово увімкнено) — агент, побачивши в
  повідомленні 🎙 спотворений термін проєкту, сам додає правило (позначка `# авто` з датою)
  і коротко про це каже; правило діє з наступної фрази. Короткі (до 3 літер) і вже відомі
  варіанти не приймаються. Вимкнено — інструмент ховається від агентів.

## Озвучення відповідей (опційно)

Типово вимкнено й не встановлено: без нього мод повний, і нічого з описаного нижче не качається.

1. У ⚙ натисніть **⬇ Встановити озвучення** (~140 МБ). Кнопка і є вашою згодою: до неї нічого
   не качається. Далі слухач створює окреме середовище Python, ставить рушій мовлення
   [Piper](https://github.com/OHF-Voice/piper1-gpl) (`piper-tts` 1.8.0, GPL-3.0-or-later,
   ~60 МБ з PyPI), качає один голос (~60–80 МБ з Hugging Face; типовий для мови інтерфейсу) і
   синтезує пробну фразу. Коли готово, «Озвучувати відповіді» вмикається саме.
2. Поки воно ввімкнено, агент отримує один додатковий розділ системного промпту: наприкінці
   **останньої** відповіді ходу він пише короткий блок — одне-три прості речення, до ~300 знаків,
   рядок починається з `🔊 Озвучити:` — і мод читає вголос лише цей блок (очищений від markdown,
   посилань і емодзі, не довше 600 знаків). У чаті блок лишається видимим як текстовий підсумок.
   Нема блоку — нічого не звучить: решту відповіді мод не читає ніколи.
3. Говорить лише чат, що зараз отримує ваш голос, і лише його головний агент (не субагенти).
   Мова блоку визначається з тексту: переважно кирилиця — український голос, інакше англійський,
   незалежно від мови інтерфейсу.

**Обірвати й не чути себе.** ✖, вимкнення 🎤, вимкнення «Озвучувати відповіді», повідомлення,
набране в чаті, чи перехід голосу в інший чат обривають озвучку; новий блок заміняє поточний.
Поки звучить, і ще 300 мс після того, як звук справді стих, слухач викидає звук мікрофона, тож
озвучка ніколи не стає командою — але й голосом її не перебити. Блок, що прийшов посеред вашої
диктовки, чекає її кінця (до 30 с, далі відкидається).

**Голоси.** У ⚙ → Розширені → *Озвучення* оберіть голос для кожної мови. Голос із ⬇ ще не на
диску: вибір такого — ваша згода на завантаження (21–114 МБ). Пропонуються лише голоси з
вільною ліцензією датасету:

| Ліцензія | Голоси |
| --- | --- |
| CC0 | `ukrainian_tts` (uk); `joe`, `mike`, `kathleen`, `reza_ibrahim` (en_US) |
| Суспільне надбання | `john`, `kristin`, `bryce`, `norman`, `ljspeech` (en_US); `cori` (en_GB) |
| Apache-2.0 | `lada`, `mykyta`, `oleksa`, `tetiana` (uk); `sam` (en_US) |
| CC BY 4.0 | `libritts_r` (en_US); `alba`, `aru`, `vctk` (en_GB) — авторство нижче |

Ліцензія — датасету голосу, як заявлено в його `MODEL_CARD` на
[rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices); та сама картка каже, чи
голос донавчено з іншого голосу Piper. Авторство голосів CC BY 4.0
([ліцензія](https://creativecommons.org/licenses/by/4.0/)):

- `libritts_r` — корпус LibriTTS-R, <http://www.openslr.org/141/>.
- `alba` — датасет Alba, Единбурзький університет (CSTR), <https://datashare.ed.ac.uk/handle/10283/3270>.
- `aru` — мовний корпус Acoustics Research Unit, Ліверпульський університет,
  <https://www.liverpool.ac.uk/architecture/research/acoustics-research-unit/speech-corpus/>.
- `vctk` — корпус CSTR VCTK, Единбурзький університет, <https://datashare.ed.ac.uk/handle/10283/3443>.

**Де лежить і як видалити.** `%USERPROFILE%\.claude\voice-mod\tts\` (`venv\`, `voices\`).
⚙ → Розширені → *Озвучення* → **Видалити озвучення** стирає цю теку й вимикає озвучку.
Журнали встановлення й власних повідомлень Piper — `tts.log` і `speak.log` поруч (лише
діагностика).

**Ліцензії.** Мод — MIT. Piper — GPL-3.0-or-later і **не входить у мод**: його нема ні в цьому
репозиторії, ні в пакеті плагіна, `install.ps1` його не ставить. Він качається з PyPI лише
після натиску кнопки, живе у власному середовищі й запускається окремою програмою
(`python -m piper`: текст на вході, звук на виході); мод ніколи не імпортує й не копіює його
код. Сирці Piper публічні за посиланням вище. Це опис того, як побудовано мод, а не юридична
консультація.

## Що мод запускає, надсилає й завантажує

Докладно — в [англійському README](README.md#what-it-runs-sends-and-downloads) і
[PRIVACY.md](PRIVACY.md). Коротко: звук обробляється лише локально й ніде не зберігається;
розпізнаний текст іде в чат Claude Code (і, з обробкою, у модель Claude через Claude Code);
моделі whisper і бібліотеки качаються з Hugging Face і PyPI; файли — лише в
`%USERPROFILE%\.claude\voice-mod`; жодної телеметрії. Озвучення (якщо встановите) додає
окремий локальний процес Piper; текст блоку синтезується локально й нікуди не йде, а Piper
(GPL-3.0-or-later, ~60 МБ, PyPI) і голос (~20–115 МБ, Hugging Face) качаються лише після натиску
кнопки; поки озвучення ввімкнено, системний промпт агента має один додатковий розділ
(`voice-mod:speak`).

## Відомі межі

- Команди йдуть у сесію, де ви востаннє щось надіслали (або закріплену 🔒): API модів
  не каже, який чат зараз на екрані ([anthropics/claude-code#103529](https://github.com/anthropics/claude-code/issues/103529)).
- Розпізнана мова — не те саме, що набраний текст: чужий голос чи відео теж можуть
  сказати «Клоде, …». Голосова команда йде агенту як ваша. Руйнівні дії (видалення,
  незворотні git-операції, надсилання назовні, зміна налаштувань і автозапуску, фонові
  й заплановані задачі) зупиняються до підтвердження — аж до вашого наступного набраного
  повідомлення. Але це список відомих небезпек, а не пісочниця: з режимом bypass
  permissions він — єдиний бар'єр. Вимикайте 🎤, коли не користуєтесь, і лишайте
  безпечний режим увімкненим.
- Мікрофон відкривається у спільному режимі: Discord/Telegram працюють паралельно,
  але голос співрозмовника з колонок теж чути.
